# Wig Fit & Care Checklist

A small, free, no-account checklist for preparing a comfortable wig fit and caring for synthetic wigs. It is a static web project: there are no build tools, trackers, cookies, or third-party JavaScript dependencies.

## What it does

- Walks through a few fit checks before a first wear.
- Offers a gentle synthetic-wig care checklist that defers to the instructions for the exact wig and fiber.
- Saves checked steps in the visitor's browser with `localStorage`; it does not send checklist data to a server.
- Works as a static page and can be hosted with GitHub Pages.

## Run locally

Open `index.html` in a browser. No install or build step is needed.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save. GitHub Pages will publish `index.html` from the repository root.

## Care notes and sources

Wig fibers and cap construction vary, so this guide deliberately avoids universal wash schedules, temperatures, and heat limits. Follow the label and product-specific instructions first. Background reading:

- [American Cancer Society: Wigs for Hair Loss](https://www.cancer.org/cancer/side-effects/hair-skin-nails/hair-loss/choosing-and-wearing-wig.html)
- [Macmillan Cancer Support: Wigs for cancer treatment](https://www.macmillan.org.uk/cancer-information-and-support/impacts-of-cancer/hair-loss/wigs-for-cancer-treatment)
- [Cancer Research UK: Wigs, hats and scarves](https://www.cancerresearchuk.org/about-cancer/coping/physically/changes-appearance/hair-loss/wigs-other-ways)

For product-specific details, see [EWIGSC's synthetic wig collection](https://e-wigs-c.com/collections/wigs). This project is maintained by EWIGSC, a wig retailer; the resource link is disclosed in the page. The checklist is general information, not medical advice or a substitute for the instructions supplied with a wig.

## Privacy

Checklist selections are stored locally in the current browser only. Use **Clear ticks** to remove them. The project does not collect names, email addresses, measurements, or health information.
